# 我幫爸爸算了一輩子的樂透，最後證明：電腦選號就好

> 這不只是一篇勸世文，更是一個工程師兒子寫給在天上老爸的程式碼。
>
> 我知道樂透不可能被算出來。
> 但我爸爸算了一輩子。他看黃曆、看新聞、看熱號冷號、看沖煞、看大事件明牌。
> 為了認真對待他的信仰，我把這些方法全部寫成程式，用台灣大樂透與威力彩的歷史資料做最嚴格的「遮罩回測」。
>
> 結論很殘酷也很簡單：**沒有任何一種算牌法，能贏過機率。**

---

## 📢 先講結論

如果你點進來，只是想知道「樂透要怎麼買比較容易中」，答案是：

**電腦選號就好。**

不是因為電腦挑的號碼比較準，而是 12 年的歷史數據告訴我們這三個現實：

* **每次開獎都是重新洗牌**：上一期開什麼，跟這期完全無關，冷號熱號根本不存在。
* **機率不聽人講故事**：管你是看農民曆、算筆畫還是看時事，號碼球就是隨機掉下來的。
* **算得越多，賠得越穩**：不管用哪門派的算牌法，只要買得夠久，最後的結果一樣是虧錢。

這份程式碼不是什麼發財秘笈，而是我花時間跑完大數據後，做出來的「打醒長輩專用圖鑑」。

---

## 👨‍💻 我為什麼做這個

我爸算樂透算了一輩子。

小時候，我常看他拿著原子筆在報紙上畫圈圈。他看黃曆、看新聞大事，把地震、空難、停電轉成號碼，也研究連號或奇偶分布。

我從來沒有想嘲笑他。相反地，我想把他的直覺認真對待到最後：
**「既然你相信，我就把它寫成程式；既然寫成程式，我就讓電腦回測 12 年。」**

其實，當這個專案跑完最終回測、得出結論時，我爸已經不在了。
看著螢幕上一整排「通通賠錢」的數字，這是我這輩子最想親口跟他說的話。如果當初能早點算給他看，或許就能讓他少花點心思在這些永遠算不準的謎題上。

如果真的有用，資料會說話。如果不中用，資料也會說實話。

---

## 🧪 回測方法：先遮住答案，再預測

為了避免那種「事後看都很準」的幻覺，我用了最嚴謹的「遮眼盲測」：

1. **遮蔽答案**：把第 N 期的開獎號碼遮住。
2. **模擬預測**：只用第 N 期以前的歷史資料產生預測號碼。
3. **實際對獎**：拿預測結果與第 N 期的真實號碼對比。
4. **全樣本執行**：從頭到尾，每一期都重複這個流程。

**這樣做確保了程式完全沒辦法「偷看」未來的答案，每一期都是實打實的硬碰硬。**

---

## 🧠 我測了哪些方法？

目前實作了 27 種策略，分為 4 大派別：

### 1. 合理派（統計數據）

* 熱號 / 冷號 / 過期號策略
* 馬可夫轉移模型（Markov Chain）
* 約束抽樣（和值、奇偶、大小分布）
* 加權多特徵集成公式

### 2. 顛覆派（反常識）

* 反熱號 / 反區間 / 反馬可夫
* 質數結界 / 費氏神秘數
* 圓周率（$\pi$）玄學 / 鏡像翻轉

### 3. 黃曆派（傳統信仰）

透過 `cnlunar` 把開獎日轉成農曆資訊：

* 農曆日數 / 六十甲子派
* 五行區間 / 沖煞反向派
* 二十八宿綜合評估

### 4. 大新聞事件派（災難明牌）

內建 30 件台灣重大事件（如：921 大地震、普悠瑪事故、0403 花蓮強震、815 大停電等）：

* 事件日期數字學
* 頭條雜湊派 / 災害交乘派

## 📊 回測結果

* **大樂透**：1397 期資料，遮罩回測 1297 期
* **威力彩**：1600 期資料，遮罩回測 1500 期

| 派別 | 大樂透 vs 隨機 | 威力彩 vs 隨機 |
| :--- | :---: | :---: |
| **合理派** | +0.016 | -0.025 |
| **顛覆派** | +0.021 | -0.006 |
| **黃曆派** | +0.012 | +0.018 |
| **新聞派** | +0.020 | +0.009 |

> **結論：沒有哪個門派能帶你穩定賺錢。**
> 那些帳面上看起來差個幾塊錢的浮動，純粹只是運氣剛好。如果農民曆真的神，就不會發生「算威力彩好像有點用，算大樂透卻完全不行」這種事。

## 🤔 為什麼人總覺得「明牌很準」？

因為我們常常只記得「中獎的那一次」：

* 照著偏方買中了一次 3 星，你可能拿出來講好幾年；但前面連續槓龜 50 次的時候，只會覺得「唉呀，這次運氣不好」。
* 某個新聞數字剛好跟開獎號碼一樣，就覺得是天意；沒對上的時候，連提都不會提。

**電腦沒有這種錯覺。它冷酷地告訴我們：在幾千期的隨機開獎面前，所有的故事都是騙人的。**

## 🛠 如何執行

### 1. 安裝環境

```powershell
pip install -r requirements.txt
```

### 2. 下載資料

```powershell
python scripts/download.py --game lotto649 --since 103
python scripts/download.py --game superlotto638 --since 100
```

### 3. 跑完整回測

```powershell
$env:PYTHONPATH="src"
$env:PYTHONIOENCODING="utf-8"

python scripts/backtest.py --game lotto649
python scripts/backtest.py --game superlotto638
```

## ⚠️ 最後的警示

這個專案不是教你怎麼中樂透，它剛好相反。

它用 27 種策略、12 年資料、近 3000 期回測證明：
我們總愛幫巧合找理由，但機率從來不聽故事。

如果你想買，請把它當成娛樂或買一張「希望票」。如果你想靠它翻身，請停下來。
我最後算出來的答案不是一組號碼，而是一句話：

> 「電腦選號就好，省下的時間多陪陪家人吧。」
