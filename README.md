> 我爸看黃曆、新聞、冷熱號，也會把生活裡的大事換成號碼。
> 我沒有想證明他錯，只是想把他相信的方法認真做完一次。

## 結論先說

**沒有任何一種選號策略，能在長期回測中穩定勝過隨機選號。**

電腦選號不是比較準，而是更誠實：它不會把巧合解讀成規律，也不會因為某次中獎，就忘記前面沒有中的幾十次。

這個專案不是預測工具。它是一份可以重複執行、檢查方法與重現結果的資料實驗。

## 這個專案做了什麼

1. 整理台灣大樂透與威力彩的歷史開獎資料。
2. 實作 27 種常見或刻意反常識的選號策略。
3. 使用 walk-forward backtest，逐期模擬當下真正能取得的資訊。
4. 將各策略與純隨機選號放在同一套條件下比較。
5. 提供 Streamlit 介面，讓使用者直接試一組號碼，看看長期持續購買的結果。

## 為什麼做這個

我爸算樂透算了一輩子。

以前常看他拿著筆在報紙上畫圈，從農民曆、社會新聞一路看到冷熱號。地震、停電、日期、筆畫，都能變成下一期的候選號碼。

與其直接說「這些都沒用」，我更想知道：把每一種方法寫成程式，放進十多年的歷史資料裡，它們到底會留下什麼結果？

等到程式跑完時，他已經不在了。

所以這個專案最後留下的，不是一組明牌，而是一個比較晚完成的回答。

## 回測方法

每一期都按照相同流程執行：

```text
只讀取該期以前的資料
        ↓
策略產生預測號碼
        ↓
公開該期實際開獎結果
        ↓
記錄命中數、獎金與累計損益
```

這種方法通常稱為 **walk-forward backtest**。它避免策略偷看未來，也避免用已知答案反推一套看似有效的規則。

## 策略分類

| 類別 | 代表方法 | 想驗證的問題 |
| --- | --- | --- |
| 統計型 | 熱號、冷號、過期號、馬可夫模型、分布約束 | 過去的頻率與排列是否能預測下一期？ |
| 反常識型 | 反熱號、質數、費氏數列、圓周率、鏡像號碼 | 刻意避開常見選法，是否會更有優勢？ |
| 黃曆型 | 農曆日數、干支、五行、沖煞、二十八宿 | 傳統曆法資訊是否和開獎結果有穩定關聯？ |
| 事件型 | 日期數字學、重大事件、新聞文字雜湊 | 社會事件中的數字是否能成為有效訊號？ |

## 回測結果

目前資料集包含：

- 大樂透：1,397 期，其中 1,297 期進入遮罩回測。
- 威力彩：1,600 期，其中 1,500 期進入遮罩回測。

下表為各類策略相對於隨機選號的平均命中差距：

| 類別 | 大樂透 | 威力彩 |
| --- | ---: | ---: |
| 統計型 | +0.016 | -0.025 |
| 反常識型 | +0.021 | -0.006 |
| 黃曆型 | +0.012 | +0.018 |
| 事件型 | +0.020 | +0.009 |

這些差距很小，而且沒有任何類別能跨遊戲維持一致優勢。某個方法在一份資料裡略高、換到另一份資料又略低，正是隨機波動常見的樣子。

## 這個實驗能回答什麼

它能回答：

- 某套選號規則在過去資料中的實際表現。
- 策略是否能在不同遊戲與不同期間維持一致結果。
- 長期持續購買時，成本、獎金與累計損益如何變化。

它不能回答：

- 下一期會開哪些號碼。
- 某組號碼是否「快要出了」。
- 未來頭獎金額與實際分獎人數。
- 任何保證獲利的投注方式。

## 執行方式

### 1. 安裝套件

```powershell
pip install -r requirements.txt
```

### 2. 下載歷史資料

```powershell
python scripts/download.py --game lotto649 --since 103
python scripts/download.py --game superlotto638 --since 100
```

### 3. 執行回測

```powershell
$env:PYTHONPATH="src"
$env:PYTHONIOENCODING="utf-8"

python scripts/backtest.py --game lotto649
python scripts/backtest.py --game superlotto638
```

### 4. 啟動網頁

```powershell
streamlit run streamlit_app.py
```

## 專案結構

```text
.
├── data/                  # 歷史開獎資料
├── scripts/
│   ├── backtest.py        # 命令列回測
│   └── download.py        # 資料下載
├── src/lotry/
│   ├── almanac.py         # 黃曆型策略
│   ├── backtest.py        # walk-forward 回測引擎
│   ├── contrarian.py      # 反常識型策略
│   ├── events.py          # 重大事件資料與策略
│   ├── games.py           # 遊戲規則
│   └── strategies.py      # 策略註冊與名稱
└── streamlit_app.py       # 互動式網頁
```

## 使用提醒

彩券可以是娛樂，但不適合作為投資、財務規劃或翻身工具。歷史回測也不能提高下一期的中獎機率。

這份程式最後算出的答案很簡單：

> 不必再花時間追明牌。真的要買，就讓電腦選一組，把它當成一次娛樂。
