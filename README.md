# 我幫爸爸算了一輩子的樂透，最後證明：交給電腦選號就好

> 這不只是勸世文，這是我寫給在天上老爸的程式。
>
> 大家都知道樂透算不出來，但他算了一輩子。看黃曆、看新聞、找冷熱號、對沖煞。
> 為了認真面對他的執著，我把這些方法全寫成程式，拿台灣大樂透和威力彩十幾年的歷史紀錄做回測。
>
> 結論很簡單：**沒有任何算牌法能贏過機率。**

---

## 📢 先講結論

如果你點進來是想找「怎麼買比較容易中」，答案是：

**交給電腦選號就好。**

不是因為電腦挑的比較準，而是 12 年的數據告訴我們：

* **每次開獎都是重新洗牌**：上一期開什麼跟這期無關，冷熱號根本不存在。
* **機率不聽人講故事**：管你看農民曆還是看時事，號碼球就是隨機掉出來的。
* **只要買得夠久，最後都是賠錢**：不管用哪一派算牌法都一樣。

這不是發財秘笈，只是我跑完資料後，寫給家人的提醒。

---

## 👨‍💻 我為什麼做這個

我爸算樂透算了一輩子。

以前常看他拿著筆在報紙上畫圈，從黃曆看到社會新聞，把地震、停電都換成號碼。
我不想笑他，反而想認真驗證看看：**「既然你這麼信，我就幫你寫成程式，讓電腦測測看這 12 年。」**

其實，當程式跑出結論時，我爸已經不在了。
看著螢幕上滿滿「虧損」的數字，這是我最想親口跟他說的話。要是能早點算給他看，或許他就能少花點心思在這些算不準的號碼上。

有沒有用，資料會說實話。

---

## 🧪 回測方法：先遮住答案，再預測

為了避開「事後看都很準」的幻覺，我用的是「遮眼盲測」：

每次預測，程式都只能用「當時」的歷史資料，完全沒辦法偷看開獎結果。從頭到尾每一期都這樣對答案。

---

## 🧠 我測了哪些方法？

實作了 27 種策略，分 4 大派別：

1. **合理派（統計數據）**：熱號/冷號/過期號、馬可夫模型、奇偶大小分布。
2. **顛覆派（反常識）**：反熱號、質數、圓周率玄學。
3. **黃曆派（傳統信仰）**：農曆日數、六十甲子、五行沖煞。
4. **大新聞事件派**：拿 921、普悠瑪、花蓮強震等 30 件大事算日子跟筆畫。

---

## 📊 回測結果

* **大樂透**：1397 期資料，遮罩回測 1297 期
* **威力彩**：1600 期資料，遮罩回測 1500 期

| 派別 | 大樂透 vs 隨機 | 威力彩 vs 隨機 |
| :--- | :---: | :---: |
| **合理派** | +0.016 | -0.025 |
| **顛覆派** | +0.021 | -0.006 |
| **黃曆派** | +0.012 | +0.018 |
| **新聞派** | +0.020 | +0.009 |

> **結論：沒有哪個門派能讓你穩定賺錢。**
> 帳面上差那幾塊錢純粹是剛好。如果農民曆真的神，總不會「算威力彩有用，算大樂透卻沒用」。

## 🤔 為什麼人總覺得「明牌很準」？

因為我們只會記得有中的那次：

* 照著偏方中了一次 3 星，可以講好幾年；前面連續槓龜 50 次，只會覺得「這次運氣不好」。
* 新聞數字剛好對上開獎號碼，就覺得是天意；沒對上的時候，提都不會提。

**電腦攤開這十幾年的紀錄，結果很現實：不管當下覺得「抓到規律」有多準，時間一拉長，終究敵不過機率。**

## 🛠 如何執行

### 1. 安裝環境

```powershell
pip install -r requirements.txt
```

### 2. 下載資料

```powershell
python scripts/download.py --game lotto649 --since 103
python scripts/download.py --game superlotto638 --since 100
```

### 3. 跑完整回測

```powershell
$env:PYTHONPATH="src"
$env:PYTHONIOENCODING="utf-8"

python scripts/backtest.py --game lotto649
python scripts/backtest.py --game superlotto638
```
