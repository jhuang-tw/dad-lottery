# 我幫爸爸算了一輩子的樂透，最後證明：電腦選號就好

> 這是一個警示文，也是一個送給爸爸的浪漫工程。
>
> 我知道樂透不可能被算出來。
> 但我爸爸算了一輩子。他看黃曆、看新聞、看熱號冷號、看沖煞、看大事件明牌。
> 所以我把這些方法全部寫成程式，用台灣大樂透與威力彩的歷史資料做遮罩回測。
>
> 結論很簡單：**沒有任何一種方法穩定贏過隨機。**

---

## 先講結論

如果你只是想知道「樂透要怎麼買比較準」，答案是：

**電腦選號就好。**

不是因為電腦選號比較神，而是因為：

- 大樂透與威力彩的開獎是隨機事件。
- 每一期與上一期獨立。
- 歷史號碼、黃曆、新聞、災難、熱門號、冷門號，都不能改變下一期機率。
- 所有策略長期下來都會貼近隨機期望值。

這個專案不是發財工具。
它是一個用程式與資料做出的家庭版反詐騙警示。

---

## 我為什麼做這個

我爸算樂透算了一輩子。

他會看黃曆，會看新聞大事，會把地震、空難、停電、政治新聞轉成號碼。
他也會看熱號、冷號、連號、尾數、奇偶、大小。

我沒有想嘲笑他。

相反地，我想把他的直覺認真對待到最後：

**既然你相信，我就把它寫成程式；既然寫成程式，我就讓它回測 12 年。**

如果真的有用，資料會說話。
如果沒有用，資料也會說話。

---

## 回測方法：先遮住答案，再預測

這個專案使用 walk-forward backtest，也就是「遮罩回測」。

流程是：

1. 把第 N 期的開獎號碼遮住。
2. 只用第 N 期以前的歷史資料產生預測號碼。
3. 再拿第 N 期的真實開獎號碼對獎。
4. 從頭到尾每一期都這樣跑。

這樣可以避免作弊。
策略不會看到未來，只能用當時已知的資料。

---

## 我測了哪些方法

目前總共做了 27 種策略，分成 4 派。

### 1. 合理派

看起來最像資料科學的方法：

- 熱號策略
- 冷號策略
- 過期號策略
- 馬可夫轉移
- 約束抽樣：和值、奇偶、大小分布
- 加權公式：多特徵集成

### 2. 顛覆派

故意反常識：

- 反熱號
- 反區間
- 鏡像翻轉
- 反馬可夫
- 質數結界
- 費氏神秘
- 上期重押
- 反常識組合
- 圓周率玄學
- 反向集成

### 3. 黃曆派

這是我爸最在意的部分。
用 `cnlunar` 把每一期開獎日轉成黃曆資訊：

- 農曆日數派
- 六十甲子派
- 五行區間派
- 沖煞反向派
- 二十八宿派
- 黃曆綜合派

### 4. 大新聞事件派

民間常見的「明牌」邏輯。
我內建了 30 件重大事件，例如：

- 921 大地震
- 八八風災
- 高雄氣爆
- 復興航空空難
- 美濃地震
- 普悠瑪事故
- 太魯閣號事故
- 0403 花蓮強震
- SARS
- COVID-19
- 815 / 303 大停電
- 太陽花學運
- 八仙塵爆

事件派策略包含：

- 日期數字學
- 重大事件對照
- 頭條雜湊派
- 災害交乘派
- 媒體輪播派

## 回測結果

資料量：

- 大樂透：1397 期資料，遮罩回測 1297 期
- 威力彩：1600 期資料，遮罩回測 1500 期

### 四派平均表現

以下數字是「相對純隨機策略」的平均命中差距。

| 派別 | 大樂透 vs 隨機 | 威力彩 vs 隨機 |
|---|---:|---:|
| 合理派 | +0.016 | -0.025 |
| 顛覆派 | +0.021 | -0.006 |
| 黃曆派 | +0.012 | +0.018 |
| 新聞派 | +0.020 | +0.009 |

看起來有些策略好像贏了。

但重點是：**沒有任何一派在兩個遊戲都穩定、大幅、可重現地贏過隨機。**

這些差距都很小，屬於隨機波動。

### 最打臉的一點

黃曆派在大樂透只比隨機多 +0.012，表現普通。
但在威力彩卻多 +0.018，看起來變強。

如果黃曆真的有預測能力，它不應該只在某個遊戲、某段資料裡看起來比較好。

這就是典型的統計噪音：

今天你會說黃曆準。
明天你會說新聞準。
後天你會說冷號準。

但把全部歷史攤開來看，最後都只是隨機。

## 為什麼人會覺得「明牌很準」

因為人會記得中的那一次，忘記沒中的那一百次。

這叫選擇性記憶，也叫生存者偏誤。

例如：

- 某天看黃曆買到 3 個號碼，會記一輩子。
- 前面 50 次沒中，會覺得「運還沒到」。
- 重大新聞剛好對到一個號碼，會覺得「有暗示」。
- 全部沒中時，只會說「這期不準」。

電腦不會有這種偏誤。

所以我把每一期都拿來算。
結果就是：沒有奇蹟。

## 那到底要不要買樂透

可以買。

但請把它當成：

- 娛樂
- 儀式
- 家庭話題
- 一張小小的希望票

不要把它當成：

- 投資
- 翻身工具
- 財務計畫
- 可以靠公式破解的系統

彩券的期望值是負的。
你買得越多，長期越接近虧損。

真正有用的不是選號公式，而是投注上限。

## 如何執行

### 安裝依賴

```powershell
pip install -r requirements.txt
```

### 下載官方歷史資料

```powershell
python scripts/download.py --game lotto649 --since 103
python scripts/download.py --game superlotto638 --since 100
```

三星彩 / 四星彩目前先手動整理資料，放成：

- `data/star3.json`
- `data/star4.json`

格式如下：

```json
[
    {"term": "115000001", "date": "2026-01-01", "numbers": [1, 2, 3]},
    {"term": "115000002", "date": "2026-01-02", "numbers": "045"}
]
```

四星彩同理：`numbers` 放 4 位，例如 `[0, 1, 2, 3]` 或 `"0123"`。
三星彩 / 四星彩會保留順序與重複 digit，不會排序。

### 跑完整對照回測

```powershell
$env:PYTHONPATH="src"
$env:PYTHONIOENCODING="utf-8"

python scripts/backtest.py --game lotto649
python scripts/backtest.py --game superlotto638
python scripts/backtest.py --game star3 --data data/star3.json --min-history 100
python scripts/backtest.py --game star4 --data data/star4.json --min-history 100
```

## 最後的警示

這個專案不是教你怎麼中樂透。

它剛好相反。

它用 27 種策略、12 年資料、接近 3000 期歷史回測，證明：

**人很會替隨機找故事，但故事不會改變機率。**

如果你真的想買，請小買。
如果你想靠它翻身，請停下來。
如果你只是想陪爸爸完成一個夢，那這個專案很適合。

我最後得到的答案不是一組號碼，而是一句話：

**電腦選號就好，剩下的是愛。**
